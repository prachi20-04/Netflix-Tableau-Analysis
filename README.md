# 🎬 Netflix Movies & TV Shows Analysis Using Tableau

## 📌 Project Overview

This project focuses on analysing Netflix Movies and TV Shows data using **Tableau Desktop**. It provides interactive visualizations to understand the distribution of Netflix content based on countries, genres, ratings, release years and content types.

The main objective is to transform raw Netflix data into meaningful insights through data visualization and interactive dashboards.

## 🎯 Project Objectives

* Analyse Movies and TV Shows distribution.
* Identify the top 10 popular genres.
* Explore country-wise content distribution.
* Analyse Netflix content ratings.
* Understand yearly content release trends.
* Explore content using interactive filters.

## 🛠️ Tools & Technologies

* **Tableau Desktop** – Dashboard creation and data visualization.
* **CSV Dataset** – Netflix Movies and TV Shows data.
* **GitHub** – Project hosting and version control.

## 📂 Dataset Description

The dataset contains information about Netflix titles, including:

| Column       | Description                  |
| ------------ | ---------------------------- |
| show_id      | Unique content ID            |
| type         | Movie or TV Show             |
| title        | Content title                |
| director     | Director name                |
| cast         | Actors                       |
| country      | Country of production        |
| date_added   | Date added to Netflix        |
| release_year | Release year                 |
| rating       | Content rating               |
| duration     | Movie duration or TV seasons |
| listed_in    | Genre                        |
| description  | Content description          |

## 📊 Dashboard Visualizations

The Tableau dashboard includes:

1. **Movies vs TV Shows Distribution** – Compares the percentage of movies and TV shows.
2. **Country-wise Distribution** – Displays Netflix content distribution on a world map.
3. **Ratings Analysis** – Shows content distribution according to ratings.
4. **Top 10 Genres** – Identifies the most common genres.
5. **Year-wise Distribution** – Analyses content trends across release years.
6. **Content Details** – Displays title, genre, rating, duration and description.

## 🎛️ Interactive Filters

The dashboard provides filters for:

* Type
* Title
* Rating
* Release Year
* Duration
* Genre

These filters allow users to explore specific categories of Netflix content.

## 🚀 How to Run the Project

1. Download or clone this repository.
2. Install Tableau Desktop.
3. Open the Tableau workbook (`.twb`).
4. If prompted, reconnect the original Netflix CSV dataset.
5. Open the dashboard and explore the visualizations.
6. Use the interactive filters to analyse the data.

**Note:** The `.twb` workbook references an external dataset. Make sure the CSV file is available and correctly connected. You can also save the workbook as `.twbx` from Tableau to package the workbook with its supporting data.

## 📈 Key Insights

* Movies represent a larger share of the analysed Netflix content than TV Shows.
* Country-wise analysis helps identify major content-producing regions.
* Ratings visualization provides insights into content classification.
* Genre analysis highlights popular content categories.
* Year-wise visualization helps understand content release patterns.
